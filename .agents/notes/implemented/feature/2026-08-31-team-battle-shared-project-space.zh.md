# Agent Note: 团战版共享项目空间与飞机大战

Status: implemented

[English](2026-08-31-team-battle-shared-project-space.md) | 中文

## Problem

各自使用本地 Agent 的成员需要共享项目决策、文件与交付证据，同时保留私有对话。模型活动与休闲游戏分数不能证明项目完成。

## Decision

团战版维护独立的已托管和已加入空间目录，每个空间拥有自己的成员与持久化项目记录。固定的部署成员名单保留为单独的旧版空间。[领域包](../../../../packages/experimental/team-battle/README.zh.md)负责成员关系、邀请、修订号校验、任务转交、文件发布和人工验收。

共享服务器只保留明确发布的协作数据。每个人的本机 Host（主机侧）保存成员凭证，并代理选定的团队操作；私有对话、目录访问和本地工具留在个人机器上。服务器根据凭证确定操作成员，在分派操作前校验空间成员关系。房主通过邀请与撤销管理访问权限，同时保留既有成果的作者归属。

只有关联产物通过验收的带权重任务才贡献项目进度。作者不能验收自己的产物。Query（提问）产生的武器只影响可重复的游戏护盾。自动生成的无内容 Query 事件属于旧版空间，不会把私有活动发布到已加入的团队。

[团队客户端](../../../../packages/experimental/client-ui-team-battle/README.zh.md)提供独立的协作视图和分离的对话游戏侧边栏。私有 Host 与 Web 配置层组装团战版，不改变官方组合包。

## Security and deployment boundary

[HTTP 连接器](../../../../packages/experimental/team-battle-connector-http/README.zh.md)提供独立且限制传输量的团队监听器，仅开放精确的创建、凭邀请加入和已认证调用路由。它不挂载私有应用 API。部署凭证授权创建项目，成员凭证仅授权访问关联空间。公网 HTTPS 由反向代理负责。本地演练身份不能通过共享服务器传输。

文件进入队列不代表 Codex 已执行。旧版投递确认是连接器的声明，共享团队文件需要明确下载或使用到本机。中断的网络操作不会自动重放。

## Alternatives considered

**保存完整私有对话。**明确发布让成员能够控制哪些信息成为共享项目证据。

**用消息数量或游戏分数代表完成度。**经人工验收的产物能够区分活动与已接受的交付。

**扩展 Agent Teams。**Agent Teams 在单一根 Session（会话）内协调子代理；团战版协调各自使用本地 Agent、且成员关系分别认证的人。

## Testing

领域与连接器测试覆盖持久化、邀请与凭证校验、撤销访问、修订号校验的协作、验收派生进度、独立监听器、有界传输和不重放修改。真实 Loader（加载器）测试覆盖可选托管，以及服务重启后保留项目数据。Web 组装快照通过生成的 Remote（远程调用）方法验证任务与验收流程。

## Consequences

共享服务器让项目记录的可用性不依赖某位成员的电脑。本地凭证存储与服务端成员校验将私有应用访问和团队协作分开。TLS 终止、服务器运行和部署级滥用防护仍由运维者负责。
