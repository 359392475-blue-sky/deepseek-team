第一次协作，按这 5 步走

准备好同事发来的完整邀请链接。

  1. 01

    安装并打开

    下载后双击解压，把 DeepSeek Harness 团战版.app 拖入「应用程序」，再打开应用。

    启动时若出现「选择项目」窗口，选择自己的本机项目文件夹，或新建一个空文件夹。这是你的本地工作目录，加入团队后仍需从空间下载同事共享的文件。

  2. 02

    连接自己的 DeepSeek

    准备好你自己的 DeepSeek API Key（模型调用密钥）。首次打开，若出现 「内测声明」，先点「继续」；在 「开始你的创作」 窗口选择 「添加 API Key」，填入 「API 密钥」，再点 「保存并继续」。

    已经跳过引导？点击侧栏底部头像打开 「账号菜单」→「设置」→「模型」，找到 DeepSeek，点旁边的 「编辑」，填写「API 密钥」后点 「保存」。首次未配置时，这张编辑卡片可能已展开。

    使用 DeepSeek 官方服务时，只需填写自己的 API Key，保留默认「API 地址」和「模型目录」。每位成员分别配置，个人密钥无需发给同事。

  3. 03

    粘贴邀请，加入项目

    在侧栏点击 「通过邀请链接加入」，粘贴完整链接，再点 「加入这个项目」。看到项目名称和自己的成员身份，就加入成功了。

    链接中 # 后的内容也要完整保留。每份邀请仅供一位同事使用，请勿转发给其他人。

  4. 04

    选择本机项目文件夹

    点击侧栏项目旁的 「打开项目对话」，选择自己的本机文件夹。需要同事的文件时，从空间的 「文件」 页下载，再放入这个目录供自己的 AI 使用。

  5. 05

    接手、共享、验收

    先读 「任务」 和 「协作纪要」。待认领的任务先点 「认领」；已交接的任务确认负责人是自己。再用 「复制任务给我的 AI」 或 「复制共享上下文给我的 AI」，粘贴到自己的项目对话继续工作。

    关键结论写入「协作纪要」；完成的文件点 「发布到团队空间」，再 「提交到任务」。另一位成员在 「验收」 页选择「验收通过」或「要求修改」，团队就能接着推进。

邀请页是什么？

公开邀请页提供复制链接和加入指引。完整 AI 对话与团队操作，需要在你自己的团队版客户端中进行。

哪些内容会共享？

团队可见已发布的任务、纪要、文件与验收结果，以及成员姓名、角色和在线状态。完整私聊、模型密钥和本机草稿不会自动共享，项目目录也不会自动同步。

下载前的常见问题

加入团队前，要准备什么？

准备 Apple Silicon Mac、自己的 DeepSeek API Key，以及同事发来的完整邀请链接。安装包适用于 macOS 15 或更高版本。查看安装与加入步骤。

本机项目文件会自动同步吗？

项目目录不会自动同步。需要共享的文件要发布到团队空间；接手时下载到自己的本机目录。个人模型密钥无需发给同事。

可以先看一个公开示例吗？

可以直接打开贪吃蛇协作示例试玩；下载并配置团队版后，再通过邀请加入自己的团队项目。

如果加入失败：先确认设备联网、邀请链接复制完整。链接已过期、被撤销或被其他设备使用时，请发起人重新生成邀请。无需向同事分享你的模型密钥。
